# 微信小游戏登录接入

实施日期：2026-10-23。适用 PHP 项目和相邻 `Project` Cocos Creator 3.8.8 工程。

## 当前实现范围

本期实现微信小游戏登录、稳定玩家 UID、独立随机 Bearer 会话、当前账号查询和退出登录。微信启动时先完成登录；网络或凭证失败时保留启动遮罩，点击重试会重新取得 `wx.login` code。浏览器预览维持原有本地流程。

登录模块本身不参与经济结算。后续已接入[云存档快照同步](云存档接入.md)，复用这里的 UID 和会话；金币、钻石、签到和兑换码仍由客户端计算，不代表已实现服务器权威结算或防作弊。

TapTap H5 已添加独立凭证验证器与显式登录路由，复用 `LoginService`、玩家表和会话服务，详见 [TapTap H5 接入](TapTap-H5接入.md)。微信与 TapTap 身份默认分开，未经验证绑定不会自动合并玩家；实际 H5 宿主授权仍需真机验收。

## 配置与运行

- 运行时：PHP 8.0+，建议使用本次验证的 PHP 8.3；扩展 `curl`、`pdo_mysql`、`mbstring`，以及 Composer 依赖需要的其他扩展。
- 数据库：本机 MySQL 5.7.26，`game-gunner`，表前缀 `kr_`。当前连接凭据在 `.env`，不要复制到客户端或提交版本库。
- 微信 AppID：`wx3dd63318911f5012`；AppSecret 仅保存在 `.env` 的 `[GAME_WECHAT] APP_SECRET`。
- `GAME.SESSION_TTL` 默认 86400 秒；`GAME.LOGIN_RATE` 默认每个来源 IP 每分钟 30 次登录。
- 本机默认 PHP 命令仍是 7.4，因此 Windows 使用 `tools/php.ps1` 自动选择本次独立 PHP 8.3；可用 `GAME_PHP_BINARY` 指定其他 PHP 8 路径。

从 PHP 目录运行：

```powershell
.\tools\php.ps1 think game:migrate
.\tools\php.ps1 tests/game/run.php
.\tools\php.ps1 -S 127.0.0.1:8787 -t public public/router.php
```

依赖首次部署时使用 PHP 8 执行 `composer install --no-dev --prefer-dist --no-interaction`。本机已按锁文件安装依赖，没有升级锁定版本。

建表命令可重复执行，不导入旧示例账号。当前用户表必须使用 InnoDB，且 `last_login_ip` 为 `VARCHAR(45)`；不符合要求时停止并报错，不自动转换旧表或扩展旧 IP 字段。以后每日执行一次 `php think game:prune` 清理过期会话和限流记录，不清理玩家账号。

微信登录优先使用项目内 `certs/cacert.pem`，通过 `CURLOPT_CAINFO` 仅设置当前微信请求的 CA；未提供该文件时沿用 PHP 的信任配置。无需修改共享 `php.ini`。部署环境保持 TLS 证书验证开启，连接失败时参考 [微信连接排查](微信连接排查.md)。

## API

正式地址：`https://nurse.kylinsit.com/game/v1`。本地地址：`http://127.0.0.1:8787/game/v1`。

| 方法 | 路径 | 身份要求 | 返回 |
|---|---|---|---|
| GET | `/health` | 无 | 服务名称和接口版本 |
| POST | `/auth/wechat` | 微信临时 code | 玩家信息、随机会话、有效期、服务器时间 |
| GET | `/auth/me` | Bearer | 玩家信息和会话有效期 |
| POST | `/auth/logout` | Bearer | 撤销当前会话 |

登录要求 `Content-Type: application/json`，正文只能包含 `code`：

```json
{"code":"wx.login-success-result.code"}
```

成功响应（字段示意，令牌必须使用实际登录结果）：

```json
{
  "player": {"id":"100001","nickname":"玩家","provider":"wechat_mini","app_id":"wx3dd63318911f5012"},
  "is_new_player": true,
  "token_info": {"access_token":"<random-token>","token_type":"Bearer","expires_in":86400,"expires_at_ms":1792814400000},
  "server_time_ms":1792728000000
}
```

查询或退出使用 `Authorization: Bearer <access_token>`。玩家 ID 用字符串传输。错误以 HTTP 状态和 `{code,message}` 返回；401 重新登录，403 为账号不可用，422 为请求参数不合法，429 为限流，502/503 为平台网络或服务配置问题。响应禁止缓存，正式接口不会输出调试栈、AppSecret、平台 session_key 或 openid。

游戏会话保存在内存，每次冷启动重新向微信获取 code，避免把旧微信账号的缓存会话当成新账号。`GameLoginClient.me()` 遇到会话 401 会重新登录并重试一次；403 不自动重试。退出和场景销毁会清理客户端会话及未完成请求。

## 表与事务

- `kr_user`：共享玩家账号，首次登录创建，不要求手机号；本期不发放初始资源。
- `kr_game_identity`：`provider + app_id + openid` 唯一，对应稳定 UID。`user_id + provider + app_id` 也唯一。
- `kr_game_session`：只存随机 token 的 SHA-256 摘要、用户归属和有效期。注销后立即拒绝当前会话；禁用或软删除玩家会拒绝其所有会话。
- `kr_game_login_throttle`：MySQL 原子递增的限流窗口，可用于多个 PHP 工作进程。默认使用实际连接来源 IP，不相信任意转发头；反向代理部署应保留正确来源地址并在可信代理层补充限流。

平台网络验证在事务外执行。账号、身份和会话在同一 InnoDB 事务中写入；并发首次登录的冲突会回滚新建账号后重读已有身份，不重复调用已经消费的微信 code。

测试使用随机 `test_login_*` 表前缀，结束只清理本次测试表，不覆盖正式账号。测试验证器位于非公开的 `tests` 目录，生产接口没有测试登录开关。

## 部署和小游戏联调

1. 部署 PHP 项目及 Composer 依赖；站点文档根目录必须是 `PHP/public`，不能是项目根目录。服务器单独配置 `.env`。旧 SQL 示例已放在 `database/legacy`，不作为公开文件发布。
2. Apache 使用 `public/.htaccess`；IIS 需启用 PHP FastCGI 与 URL Rewrite，可使用 `public/web.config`；Nginx 使用 `try_files $uri $uri/ /index.php?s=$uri&$query_string;` 或等价 PATH_INFO 转发，并保留 Authorization 请求头。
3. 域名下原有 `/forest-gunner/` 静态资源需继续保留。若 PHP 与资源不在同一站点，只把 `/game/` 路由转发到 PHP 服务，保持请求路径。
4. 执行迁移，确认正式 `/game/v1/health` 返回 `forest-gunner-game`。本地接口通过不表示域名已部署。
5. 在微信公众平台将 `https://nurse.kylinsit.com` 加入 **request 合法域名**，核对小游戏 AppID。AppSecret 不写入 `game.js`、Cocos 配置或网络请求正文。
6. Cocos `session/GameBackendConfig.ts` 已配置正式域名；`test` 构建使用回环本地地址，仅适合本机微信开发者工具，并需开启开发时的“不校验合法域名”。手机真机使用 HTTPS 正式或测试域名，不能访问电脑的 `127.0.0.1`。
7. 用真实微信账号验证首次登录、再次登录 UID 不变、断网重试和禁用账号；只有这一步通过，才能认定有效微信 code 的完整链路通过。CLI 模拟平台测试不能替代真机验证。

部署包内容和逐步操作见 [手动部署说明](手动部署说明.md)。

参考：[微信 code2Session 官方文档](https://developers.weixin.qq.com/minigame/dev/api-backend/open-api/login/auth.code2Session.html)、[微信网络配置](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/network.html)。
