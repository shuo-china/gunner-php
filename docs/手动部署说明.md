# PHP 后端手动部署

目标接口：`https://nurse.kylinsit.com/game/v1`。由你上传和配置服务器，本次没有发布线上服务或上传微信小游戏版本。

## 1. 上传文件

将交付的 `php-backend.zip` 解压到服务器独立目录。压缩包内就是 PHP 项目根目录，已带按锁文件安装的生产依赖 `vendor`。无需在服务器升级 Composer 包。

压缩包不含真实 `.env`、数据库内容、旧示例 SQL、测试程序、本机运行日志和 PHP 可执行程序。源代码仍在本机 `E:\gunner\PHP`。

服务器安装 PHP 8.0.2+，建议 PHP 8.3，启用 `curl`、`pdo_mysql`、`mbstring`、`fileinfo`、`openssl`、`gd` 等依赖所需扩展。更新版部署包附带 `certs/cacert.pem`，微信登录仅为自己的请求指定这份 CA，不需要修改共享 `php.ini`。现有部署可覆盖 `wechat-project-ca-fix.zip`，详见 [微信连接排查](微信连接排查.md)。

奖励核验版本还需要 Node.js 20+ 和 PHP `proc_open`，并完整上传 `bin/reward-worker.cjs`、`bin/reward-runtime/`、`config/rewards-economy.json`。Node 可执行路径通过 `[GAME] NODE_BINARY` 配置；详细上线步骤见[奖励核验接入](奖励核验接入.md)。

## 2. 配置数据库和密钥

在服务器创建数据库（已经存在则保留）：

```sql
CREATE DATABASE IF NOT EXISTS `game-gunner`
  CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

将本机 `E:\gunner\PHP\.env` 单独复制到服务器项目根目录，并按服务器环境修改 `[DATABASE]` 的地址、账号和密码。本机文件已经填好你提供的微信配置。也可以从 `.env.example` 复制为 `.env` 后自行填写；示例中的占位值不能用于登录。

确认 `APP_DEBUG = false`，微信 AppID 为 `wx3dd63318911f5012`，`[GAME_WECHAT] APP_SECRET` 为对应密钥。密钥只保留在后端，`.env` 不放进 `public` 或小游戏包。

在服务器项目根目录执行：

```sh
php think game:migrate
```

该命令可以重复执行，将创建登录表、云存档表、`003_game_rewards.sql` 中的四张奖励表和 `004_game_share.sql` 中的每日分享表。不会导入旧后台示例数据。当前用户表必须使用 InnoDB，且 `last_login_ip` 为 `VARCHAR(45)`；不符合要求时停止并报错，不自动转换旧结构。客户端必须在后端迁移、云存档及奖励路由就绪后更新，完整步骤见[云存档接入](云存档接入.md)和[奖励核验接入](奖励核验接入.md)。生成配置必须包含 `dailyShare`，客户端、PHP 和导出运行模块使用一致的当前存档结构。已有快照缺奖励账本或上传省略分享镜像时拒绝操作，不通过默认账本补齐；只有尚无快照的新账号正常初始化。

## 3. 配置站点

站点文档根目录指向解压目录下的 `public`；PHP 进程需有 `runtime` 的写入权限。保留域名原有 `/forest-gunner/` 游戏资源目录；若后端单独部署，可只把 `/game/` 转发至 PHP 服务，保留完整路径和 `Authorization` 请求头。

- IIS：安装和启用 PHP FastCGI、URL Rewrite，包内 `public/web.config` 已提供路由规则。需要自己绑定 HTTPS 证书和域名。
- Apache：启用 `mod_rewrite`，允许加载 `public/.htaccess`。
- Nginx：在现有 PHP-FPM 配置上设置路由，例如 `location / { try_files $uri $uri/ /index.php?s=$uri&$query_string; }`；PHP 转发保留 Authorization 头。

打开 `https://nurse.kylinsit.com/game/v1/health`，应返回 HTTP 200：

```json
{"service":"forest-gunner-game","version":1}
```

再访问 `/game/v1/auth/me`，未带登录令牌时应为 HTTP 401 和 `SESSION_INVALID`。健康检查只证明路由可用，不替代数据库迁移及真实微信登录验证。

若健康检查仍为 404，先检查站点根目录、PHP 处理程序和重写规则。若提示 PHP 版本不符，确认网站实际运行的 PHP 和命令行 PHP 都已切换至 PHP 8。

## 4. 微信端联调

在微信公众平台把 `https://nurse.kylinsit.com` 加入小游戏的 **request 合法域名**。游戏代码已使用该正式地址，需要重新构建更新后的 `E:\gunner\Project`；此前发布的小游戏版本不会自动获得登录代码。

使用正式环境构建进行真机测试：首次进入创建账号，重复进入保持 UID 不变，断网显示重试。有效微信 code 必须来自同一个 AppID 的 `wx.login`，不能手工编造。

`test` 构建默认连 `http://127.0.0.1:8787/game/v1`，只用于本机微信开发者工具；手机无法通过这个地址访问电脑。

## 5. 日常清理

可在服务器任务计划中每日执行一次：

```sh
php think game:prune
```

只清理过期会话与限流窗口，保留玩家账号。云存档的历史和普通保存回执在成功保存时按保留策略清理。奖励回执及领奖记录永久保留，不随普通存档回执清理；离线、签到、每日分享额度和兑换码由后端核验。TapTap 尚未接入。
